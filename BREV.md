# NVIDIA Brev: воспроизводимый запуск

Brev используется как независимая среда проверки и доказательство NVIDIA-
интеграции. Судейская логика `Agent.act()` не зависит от сети, GPU или Brev и
продолжает работать локально.

## Конфигурация Brev

1. Создайте GPU Instance или Launchable в режиме **VM Mode**.
2. Выберите одну недорогую доступную NVIDIA GPU. Вычисления агента CPU-bound,
   поэтому дорогая H100 не даёт практического преимущества.
3. Не открывайте сетевые порты: проект запускается как batch-проверка.
4. Подключите репозиторий:

   ```text
   https://github.com/BAITC-Hacks/hack-033bf26b-byteford-united.git
   ```

5. В терминале Brev выполните:

   ```bash
   cd /home/ubuntu/workspace/hack-033bf26b-byteford-united
   git pull --ff-only origin main
   bash scripts/brev_setup.sh
   ```

Если Brev клонировал проект под другим именем, перейдите в фактический каталог
репозитория. Число прогонов можно изменить без редактирования кода:

```bash
BREV_EVAL_RUNS=50 bash scripts/brev_setup.sh
```

## Что сохраняется как evidence

После успешного запуска каталог `.brev-evidence/` содержит:

- `report.json` — commit SHA, чистота checkout до и после проверки, ОС, Python,
  версии зависимостей, NVIDIA GPU, длительности, exit codes, хеши логов и
  SHA-256 файла `submission.csv`;
- `unittest.log` — результаты автоматических тестов;
- `local_eval.log` — устойчивость агента на нескольких seed;
- `benchmark.log` — A/B-сравнение historical priors и fallback;
- `make_submission.log` — воспроизводимая генерация submission.

`.brev-evidence/` исключён из Git: это отчёт конкретного запуска, а не исходный
код. Для презентации сохраните `report.json` отдельно и сделайте скриншот
терминала с успешными проверками и строкой `NVIDIA GPU`. Для финального evidence
проверьте, что `checkout_clean_before` равен `true`, а все `exit_code` равны `0`.

## Безопасность

- Скрипты не читают и не печатают API-ключи или произвольные переменные среды.
- Не добавляйте `.env`, Brev credentials, SSH-ключи и токены в репозиторий.
- Если позже понадобится NVIDIA Build API, передавайте ключ через Brev Secret
  или Launch Parameter без значения по умолчанию.
- Наличие NVIDIA API не должно влиять на числовое решение агента: сетевой слой
  остаётся опциональным и обязан иметь локальный fallback.

## Что сказать на демонстрации

> Мы используем NVIDIA Brev как чистую воспроизводимую GPU-среду. Один скрипт
> разворачивает зависимости, фиксирует GPU и commit SHA, запускает тесты,
> устойчивость, A/B benchmark и заново создаёт submission. Судейский агент при
> этом остаётся автономным и не зависит от доступности внешнего API.
